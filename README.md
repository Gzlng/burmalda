# 🎰 Бурмалда (Burmalda)

Простой и весёлый мини-слот (с Мамой-птицей) с консольной и графической версией. Испытай свою удачу: если выпадут три одинаковых буриалды, тебя ждёт музыкальный перформанс! 🎵

> Проект создан "for soul" (для души) и хорошего бурмалждения.

## ✨ Возможности

- 🖥️ **Консольная версия**: быстрый запуск и генерация случайных символов.
- 🖼️ **Графическая версия (GUI)**: наглядная визуализация на базе `tkinter` с использованием изображений.
- 🎶 **Джекпот**: при совпадении трёх одинаковых картинок автоматически воспроизводится аудиофайл (`pesenka.mp3`).
- ⚙️ **Гибкая настройка**: возможность легко изменить набор изображений, символов или звуков.

## 📦 Установка


1. Убедитесь, что у вас установлен **Python 3.x** и библиотека **playsound3**, если нет, то
 ```bash
pip install playsound3
 ```
2. Склонируйте этот репозиторий:
   ```bash
   git clone https://github.com/Gzlng/burmalda.git
   cd burmalda
   ```

## 🛠️ Настройка

    Режим отладки (гарантированный джекпот): В файле burmalda_gui.py есть закомментированная строка,
    для стопроцентного выигрыша нужно убрать "#"  перед ней
